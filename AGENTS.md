# AGENTS.md

Operating guide and rules of engagement for AI agents working in this repository.

---

## Purpose & Context

This repository serves a dual purpose:
1. An active, hands-on learning workspace.
2. A long-term public portfolio demonstrating production-grade AI Engineering capability.

### Developer Profile
- **Experience**: Experienced Software Engineer with background in TypeScript/JavaScript, backend development, full-stack architecture, REST APIs, PostgreSQL, Docker, Linux, enterprise systems, system integration, and production deployment.
- **Career Trajectory**: Software Engineer → Backend Engineer with AI capabilities → Applied AI Engineer / AI Engineer → Production AI Engineer.

> [!IMPORTANT]
> **No Elementary Fundamentals**: Do not attempt to teach general programming fundamentals (loops, basic conditional logic, elementary OOP definitions, standard git commands) unless an actual knowledge gap is specifically identified by the user. Focus on Python-specific mechanics, language semantics, and AI engineering practices.

## Progress Update Protocol

When requested to "update progress", "record progress", "mark this done", or equivalent:

1. Read and inspect [`PROGRESS.md`](file:///d:/Projects/OTHER/ai-engineering-roadmap/PROGRESS.md).
2. Inspect the repository for newly added code, notes, exercises, or artifacts.
3. Update only items with verified completion.
4. Record current position within course materials or learning tracks.
5. Log key architectural or strategic decisions.
6. Set the next concrete, actionable learning step.
7. Keep formatting concise, clean, and structured.
8. Avoid rewriting unrelated sections.
9. Commit updates with a descriptive, progress-related commit message when requested.

## Learning Philosophy

Optimize continuously for:

$$\text{Understanding} \longrightarrow \text{Implementation} \longrightarrow \text{Experimentation} \longrightarrow \text{Production Thinking} \longrightarrow \text{Portfolio Evidence}$$

- **No Vanity Metrics**: Do not optimize for course completion percentages or certificate counts. Courses are tools, not end achievements.
- **Avoid Tutorial Clones**: Avoid generic or trivial tutorial projects.
- **Enterprise-Grade Focus**: Prioritize production-relevant applications, including:
  - Enterprise knowledge systems & document intelligence
  - Retrieval-Augmented Generation (RAG) systems
  - Domain-specific automation (procurement, HR, finance, logistics)
  - Autonomous AI agents & tool integration
  - Semantic search & vector indexing
  - System evaluation, tracing, & observability

## Notes Policy

Notes in this repository must be high-signal and concise. Only document:
- Genuinely new domain concepts
- Python-specific execution behaviors and language semantics
- Core AI / LLM principles and mental models
- Key contrasts with TypeScript/Node.js where illustrative
- Easily forgotten syntaxes or edge cases
- Production, performance, and scaling considerations

> [!WARNING]
> Do not generate filler notes or artificial documentation to simulate repository activity.

## Roadmap Modification Policy

The roadmap is dynamic and must adapt to shifts in AI engineering standards, tooling, and market requirements.
