# Stage 0 — Python for AI

## Overview

Stage 0 is **not** intended to teach programming fundamentals. As an experienced software developer with TypeScript and backend experience, the objective is to become comfortable using Python as an experienced developer before moving into the AI ecosystem.

## Goal

Gain fluency in Python syntax, execution semantics, modern tooling, and key backend libraries required for production AI application engineering.

---

## Topics to Cover

- Python syntax differences relevant to experienced developers
- Functions
- Data structures
- Comprehensions
- OOP
- Modules and packages
- Exceptions
- File handling
- Type hints
- Decorators
- Iterators and generators
- async/await
- HTTP/API usage
- Pydantic
- FastAPI basics
- Python project structure
- dependency/environment management with uv
- testing basics

---

## Directory Structure

- `notes/` — Concise topic notes and reference cheat sheets.
- `exercises/` — Targeted code exercises.
- `mini-projects/` — Applied mini-projects.
